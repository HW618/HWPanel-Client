# 契约 · 阈值与轮询策略

## 变更

- 2026-11-27 / T06 / 初版

## 1. 资源阈值

来源：`tokens.json → components.loadThresholds`

| 区间 | 档 | 颜色令牌 |
|---|---|---|
| `< 70%` | normal | 图表维度色（`chart.cpu` / `chart.memory` / `chart.disk`） |
| `70% – 89%` | warning | `status.warning` |
| `≥ 90%` | danger | `status.danger` |

```ts
export function loadTone(percent: number): 'normal' | 'warning' | 'danger';
```

**边界值**：69.9 → normal；70 → warning；89.9 → warning；90 → danger。整数化只在展示层做，判定用原始值。

## 2. 轮询

| 场景 | 区间 | 说明 |
|---|---|---|
| 概览实时 | 3s / 5s（默认）/ 10s / 手动 | 用户可在「更多 → 概览刷新频率」修改 |
| 指标下钻（实时部分） | 同上 | 与概览共享用户设置 |
| 日志实时追踪 | 1s（增量拉取） | 仅在追踪开关打开且页面可见时 |
| 任务执行日志 | 2s | 状态离开 `running` 即停 |
| 服务器在线探测 | 30s | 仅在「全部面板总览」可见时 |

统一门控：`AppState === 'active'` **且** 页面可见。任一不满足 → 暂停；恢复时**先立即拉一次**再重新排程（AC-03.3）。

## 3. 限制

| 项 | 限制 |
|---|---|
| 日志默认行数 | 200 |
| 日志可选行数 | 100 / 200 / 500 / 1000 |
| 日志渲染上限 | 1000 行（超出丢弃最旧） |
| 列表分页 | 容器/应用/任务 20 条/页，滚动加载 |
| 并行请求 | 同一服务器 ≤ 4；跨服务器不限制 |

## 4. 展示格式

- 百分比：整数 + `%`；`tabular-nums`。
- 速率：`B/s → KB/s → MB/s`，保留 1 位小数；0 显示 `0 B/s` 不显示 `0.0`。
- 容量：`GB` 保留 1 位小数。
- 时间：距今用相对描述（`3 分钟前`），精确值放副标题/长按；跨天用 `MM-DD HH:mm`。
