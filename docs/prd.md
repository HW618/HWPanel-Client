## 1. 产品背景与核心目标

### 1.1 问题陈述
使用 1Panel v2 管理单台或多台 Linux 服务器的个人开发者与运维人员，在脱离电脑（通勤、外出、值班）时，需要随时查看服务器运行负载、排查容器或计划任务异常、执行应用升级或容器重启等轻量运维操作。直接通过手机浏览器访问 1Panel Web 控制台存在页面适配不佳、多实例反复登录切换繁琐、小屏高危操作易误触等痛点。

### 1.2 产品目标
打造面向 1Panel v2 的原生体验移动端客户端 **HWPanel**（覆盖 iOS 与 Android）：
1. **多实例统一管理**：支持添加多台独立 1Panel v2 实例，按用户偏好在「全部面板总览」与「默认单机概览」之间无缝切换。
2. **类消费级监控体验**：借鉴飞牛 fnOS 移动端的清爽卡片视觉，将 CPU、内存、磁盘、网络与进程 Top5 以低认知负担的方式呈现，并支持点击下钻查看历史趋势与细粒度详情。
3. **安全高效的轻量运维**：在移动端闭环核心高频操作——容器与 Compose 编排操控、应用商店安装/升级/卸载、计划任务执行与日志排查、网站状态巡检，并通过统一的强提示二次确认机制防止误触破坏生产环境。

## 2. 需求范围（In-Scope vs Out-of-Scope）

### 2.1 一期范围（MVP In-Scope）
| 模块 | 一期包含能力 |
| --- | --- |
| **多实例管理** | 添加/编辑/删除多台独立 1Panel v2 面板；连接测试；设置/取消「默认服务器」；全部面板总览卡片流；单机顶部胶囊快速切换服务器。 |
| **登录与鉴权** | 仅支持 **API-Key** 与 **用户名密码** 两种登录方式；支持面板地址（HTTP/HTTPS + 端口）、可选安全入口路径（Entrance）、信任自签名 HTTPS 证书开关；遇到面板开启验证码或 MFA 时给出清晰输入/降级处理（详见 4.2 节）；本地加密存储凭据（iOS Keychain / Android Keystore）。 |
| **概览与监控下钻** | 实时展示 CPU（使用率、核心数、Load 1/5/15）、内存（物理内存 + Swap）、磁盘（主挂载点容量与 I/O）、网络（上下行速率与累计流量）、进程 Top5；点击各卡片下钻查看多核/多挂载点/多网卡详情、时间区间历史趋势图（面板开启监控历史时）、完整进程列表（**只读**，支持按 CPU/内存排序与搜索）。 |
| **容器管理** | 容器列表（支持全部/运行中/已停止/异常筛选与名称搜索）；启动、停止、重启、删除；容器详情（基本信息、端口、环境变量、卷、网络）；实时/历史日志查看（搜索、行数选择、自动滚底、复制）。 |
| **容器编排（Compose）** | 编排列表（名称、服务数、状态、搜索）；启动、停止、重启、重建、删除；查看编排关联服务与实时日志；修改编排 YAML（等宽源码编辑器、基础缩进/语法格式校验、保存并触发更新）。 |
| **应用商店** | 浏览应用商店（分类筛选、关键词搜索、应用详情与版本参数）；浏览已安装应用（运行状态、可升级提示）；应用安装（常用必填参数表单 + 异步安装任务进度与实时日志）；应用升级；应用卸载（强提示二次确认，含默认不勾选的“同时清理数据/镜像”复选框）。 |
| **计划任务** | 已创建任务列表（名称、类型、周期表达式、最近执行状态与时间）；手动立即执行；停止运行中任务；启用/禁用任务切换；删除任务；查看历史执行记录与执行日志（支持复制）。 |
| **网站管理（基础只读）** | 查看当前面板管理的网站列表（域名、状态、网站类型/运行环境、SSL 证书状态与到期提醒）与基础详情页（多域名、代理/端口、环境、证书信息）。**一期严格保持纯只读，不提供站点新建、编辑、Nginx 配置与启停变更。** |
| **外观与基础设置** | 浅色 / 深色 / 跟随系统 三态主题切换；概览实时轮询间隔设置（如 3s / 5s / 10s / 手动）；关于与本地安全说明。 |

### 2.2 明确排除范围（Out-of-Scope / 规划至 Phase 2）
以下能力**严禁在一期实现或暴露未完成的假交互入口**：
1. 网站配置修改、新建网站、反向代理/OpenResty 规则编辑、SSL 证书申请与续签；
2. 容器 Web Terminal（SSH/Exec 交互终端）与新建单个容器；
3. 计划任务的新建与编辑；
4. Compose 编排的新建（一期仅支持查看与修改已有编排）；
5. 应用商店高级 Compose 覆盖编辑、自定义/私有应用仓库（X-Pack）；
6. 1Panel v2 专业版主从节点（Master-Node）多机纳管；
7. App 本地生物识别锁（Face ID / 指纹 / PIN）；
8. 服务端推送告警（APNs / FCM）与桌面小组件；
9. 文件管理、主机终端、AI 运维助手；
10. 多语言国际化（一期仅简体中文）与 1Panel v1 历史版本兼容。

## 3. 信息架构与 5 Tab 导航设计

### 3.1 启动路由状态机
```
App 启动
  ├─ 本地无已保存服务器 ──▶ [全部面板总览页（空态引导）] ──▶ 点击「添加服务器」──▶ [添加/编辑面板页]
  ├─ 本地有服务器 & 未设置默认服务器 ──▶ [全部面板总览页（多机卡片流）] ──▶ 点击在线卡片 ──▶ 进入该机 [单机主框架（Tab 1 概览）]
  └─ 本地有服务器 & 已设置默认服务器 ──▶ 直接进入默认机的 [单机主框架（Tab 1 概览）]
```
- 在任意单机 Tab（Tab 1–4）或概览页顶部，提供**服务器切换胶囊**（展示当前服务器在线圆点 + 名称 + 下拉箭头）：点击弹出底部「切换服务器 Sheet」，支持：
  1. 一键切换至其他已保存的面板实例；
  2. 点击「查看全部面板」返回「全部面板总览页」；
  3. 快捷入口「添加新面板」。

### 3.2 底部 5 Tab 一级导航（单机主框架）
严格固定为 **5 个一级 Tab**，对齐飞牛 fnOS 的极简线性图标 + 底部激活圆点视觉规范：

| 序号 | Tab 名称 | 图标语义 | 核心承载页面与二级路径 |
| --- | --- | --- | --- |
| **1** | **概览** | 仪表盘 / 脉搏 | 单机资源概览页（CPU/内存/磁盘/网络/进程 Top5）→ 指标下钻详情页（趋势图与明细） |
| **2** | **容器** | 立方体 / 集装箱 | 顶部分段切换：**「容器」** / **「编排」** → 容器详情与日志页 / Compose 详情、YAML 编辑器与日志页 |
| **3** | **应用** | 网格应用商店 | 顶部分段切换：**「应用商店」** / **「已安装」** → 应用详情页 → 安装参数配置页 → 安装/升级任务进度日志页 → 已安装详情页 |
| **4** | **任务** | 时钟 / 清单 | 计划任务列表页 → 任务详情与执行历史日志页 |
| **5** | **更多** | 菜单 / 设置齿轮 | 入口分组页：当前面板摘要与「多面板管理」、**「网站管理（只读）」**、「外观与刷新设置」、「关于与安全说明」 |

## 4. 功能需求与业务规则详述

### 4.1 多实例管理（全部面板总览 & 实例 CRUD）
- **全部面板总览卡片流**：
  - 顶部汇总区显示：`全部面板（N） · 在线 X · 离线 Y`，右侧提供 `+` 添加按钮与下拉刷新。
  - 搜索栏支持按「服务器备注名」或「主机地址」本地实时过滤。
  - 单张服务器卡片展示：在线/离线状态圆点与标签、备注名、`默认` 徽标（若设为默认）、主机地址（等宽字体）、1Panel 版本标签（如 `v2.0.x`）、CPU 与内存迷你进度条（离线时置灰并显示「无法连接 · 最后在线时间」）。
  - 卡片操作：点击卡片进入该机单机概览（离线卡片点击可进入查看上次连接错误并触发重试/编辑）；卡片右上角 `···` 菜单支持「设为默认服务器 / 取消默认」「测试连接」「编辑连接」「删除服务器（二次确认）」。
- **默认服务器唯一性**：同一时刻最多仅有 1 台服务器被标记为「默认服务器」；将 B 设为默认时自动取消 A 的默认标记。

### 4.2 添加/编辑面板与登录鉴权（API-Key / 用户名密码）
- **通用连接字段**：
  - **服务器名称**（必填，1–32 字符，如「生产主节点-华东」）。
  - **面板地址**（必填，支持 `http://` 或 `https://` + 域名/IP + 可选端口，前端自动校验 URL 格式并剔除尾部多余斜杠）。
  - **安全入口（Entrance）**（选填，1Panel 安全入口路径，不含斜杠或自动规范化；若未填则按根路径请求）。
  - **允许自签名 HTTPS 证书**（开关，默认关闭；开启时在下方显示黄色安全提示：「仅建议在内网或受控 VPN 环境下开启」）。
- **认证模式分段切换（仅 2 种）**：
  1. **API-Key 模式**：
     - 字段：`API-Key`（密文输入框，支持显隐切换）。
     - 签名规则（产品边界说明）：按 1Panel v2 开放 API 规范随请求携带时间戳与 Token 签名；若连接测试返回 `401 / IP 未在白名单 / 时间戳过期`，必须展示可执行的中文错误指引（例如提示检查面板「API 接口设置」中的启用状态、IP 白名单及设备系统时间同步）。
  2. **用户名密码模式**：
     - 字段：`用户名`（必填）、`密码`（必填，密文显隐切换）。
     - **1Panel 登录安全边界处理**：
       - 若面板开启 **安全入口** 但用户未填写或填错：返回入口校验失败提示，引导用户补充「安全入口」字段。
       - 若面板返回需要 **图形验证码**：在登录提交流程中弹出「图形验证码弹窗」，加载面板下发的验证码图片与刷新按钮，用户输入后继续认证。
       - 若面板开启 **MFA（TOTP 两步验证）**：在账号密码校验通过后无缝进入「两步验证步骤弹窗」，输入 6 位动态验证码完成会话建立。
       - 会话过期处理：当用户名密码登录态（Token/Cookie）失效时，拦截 401 并提示用户「登录会话已过期，请重新验证」并提供一键重新登录入口。
- **测试连接与保存**：
  - 提供「测试连接」次要按钮与「保存并连接」主按钮；展示连接中 Loading、成功横幅（显示识别到的 1Panel 版本号与主机名）、失败横幅（显示具体原因：网络超时/证书不受信任/认证失败/版本不兼容提示）。
  - **本地存储安全**：API-Key、密码与会话凭证严禁明文写入普通配置文件或日志，必须使用 iOS Keychain / Android Keystore 安全存储；删除服务器时必须同步彻底清除本地凭据。

### 4.3 概览页与指标下钻
- **单机概览页（Tab 1）**：
  - **顶部栏**：左侧服务器切换胶囊（状态点 + 名称 + 下拉箭头），右侧手动刷新按钮（刷新中旋转）与自动轮询指示（如 `5s 实时`）。
  - **主机摘要条**：展示主机名、操作系统、运行时长（Uptime）与 1Panel 版本。
  - **核心资源卡片（可点击下钻）**：
    - 三环进度仪表盘：**CPU 使用率（%）**、**物理内存使用率（% + 已用/总量）**、**主磁盘使用率（% + 已用/总量）**。
    - 负载状态色规则：`< 70%` 科技蓝（正常）、`70%–89%` 琥珀黄（预警）、`≥ 90%` 珊瑚红（告警）。
    - 底部轻量指标条：`系统负载 Load 1 / 5 / 15`、`Swap 使用率`。
  - **磁盘与网络卡片（可点击下钻）**：
    - **网络卡片**：当前实时上行速率（`↑ KB/s 或 MB/s`）、下行速率（`↓`）、当前网卡名与累计收发流量。
    - **磁盘 I/O 卡片**：实时读速率、写速率、挂载点总数摘要。
  - **进程 Top5 卡片（可点击下钻）**：
    - 卡片右上角支持切换排序维度：**「按 CPU」** / **「按内存」**。
    - 展示前 5 个进程：进程名、PID、CPU 占用（%）、内存占用（MB / %）。
    - 底部「查看全部进程 ›」进入下钻页。
- **下钻详情页**：
  - 支持维度：CPU 详情（各逻辑核心负载 + Load 趋势）、内存详情（物理内存/缓存/缓冲区/Swap 拆分 + 趋势）、磁盘详情（所有挂载点容量进度条 + 磁盘读写 I/O 趋势）、网络详情（网卡选择器 + 实时/历史上下行趋势 + 累计收发统计）、进程详情（**完整只读进程列表**，核心字段为进程名 / PID / CPU% / 内存，若 1Panel 接口返回用户字段则作为可选扩展列展示；支持按名称/PID 搜索与按 CPU/内存切换排序，无 Kill 操作按钮）。
  - **历史趋势图边界**：提供 `1小时` / `6小时` / `24小时` 时间段切换；若 1Panel 面板端未开启系统监控历史记录或无历史数据，趋势图区域展示清晰提示空态（「当前面板未开启监控历史记录，请前往 1Panel Web 端开启」），同时上方实时指标仍正常展示。

### 4.4 容器与容器编排（Compose）（Tab 2）
- **顶部分段控制器**：`容器` | `编排 (Compose)`。
- **容器列表与操作**：
  - 搜索框（按容器名/镜像名过滤）+ 状态筛选胶囊（`全部` / `运行中` / `已停止` / `异常`）。
  - 列表卡片字段：容器名称、状态点与中文状态徽标（运行中/已停止/重启中/已退出）、镜像名与 Tag、端口映射摘要、CPU/内存瞬时占用（运行中展示）。
  - 行内快捷操作或展开操作栏：
    - 运行中：主操作「停止」、次操作「重启」、菜单内「查看日志」「删除」；
    - 已停止/已退出：主操作「启动」、次操作「重启（置灰或可选）」、菜单内「查看日志」「删除」。
  - **容器详情页**：
    - 顶部状态头 + 操作按钮组（启动/停止/重启/删除，按钮可用状态严格随容器当前运行态联动）。
    - Tab 切换：**「概览信息」**（ID、镜像、创建时间、端口映射、网络、挂载卷、环境变量——敏感变量默认脱敏或支持点击显隐）与 **「运行日志」**（支持切换最近 `100 / 200（默认） / 500 / 1000` 行、实时追踪开关、关键词搜索高亮、自动滚动到底部、一键复制全部可见日志）。
- **编排（Compose）列表与操作**：
  - 搜索框 + 状态筛选（`全部` / `运行中` / `部分运行` / `已停止`）。
  - 编排卡片：编排名称、包含容器数（如 `3/3 运行中`）、状态徽标、更新时间。
  - 操作能力：**启动、停止、重启、重建（Rebuild）、查看日志、编辑 YAML、删除**。
  - **编排详情页**：
    - Tab 1 **「服务列表」**：列出该编排下所有子容器状态，点击可跳转对应容器详情。
    - Tab 2 **「YAML 配置」**：等宽字体代码块视图，点击「编辑」进入编辑态；保存前执行客户端基础语法校验（非空、Tab 制表符告警、基础 YAML 解析校验），校验不通过时高亮错误行号并阻止提交；保存成功后支持选择「仅保存」或「保存并重建生效（触发二次确认）」。
    - Tab 3 **「编排日志」**：实时/历史合并日志查看，支持搜索、行数切换与复制。

### 4.5 应用商店与已安装应用（Tab 3）
- **顶部分段控制器**：`应用商店` | `已安装`（若存在可升级应用，显示数字角标）。
- **应用商店视图**：

### 4.8 高危操作防误触统一规则
以下操作属于**破坏性或可能中断业务的高危操作**，必须严格执行统一确认规范：

| 高危操作 | 弹窗形态 | 必须展示内容 | 额外选项与默认态 | 确认按钮样式 |
| --- | --- | --- | --- | --- |
| **删除容器** | 居中强提示弹窗 | 容器名称 + 「删除后容器实例及未持久化数据将不可恢复」 | 可选「强制删除运行中容器」（仅当容器运行中时展示，默认不勾选） | 危险红主按钮（`确认删除`） |
| **删除编排（Compose）** | 居中强提示弹窗 | 编排名称 + 关联容器数 + 「将停止并移除该编排管理的所有容器」 | 无 | 危险红主按钮（`确认删除`） |
| **重建编排（Rebuild）** | 底部确认抽屉/弹窗 | 编排名称 + 「将重新拉取/构建并重启编排下服务，期间业务会短暂中断」 | 无 | 警告/主色确认按钮（`确认重建`） |
| **卸载应用** | 居中强提示弹窗 | 应用实例名称 + 版本 + 「卸载将停止并移除该应用服务」 | **复选框 1**：「同时删除应用持久化数据与备份」（**默认不勾选**）<br>**复选框 2**：「同时删除关联容器镜像」（**默认不勾选**） | 危险红主按钮（`确认卸载`） |
| **删除计划任务** | 居中强提示弹窗 | 任务名称 + 「删除后定时调度与关联执行记录将被清除且不可恢复」 | 无 | 危险红主按钮（`确认删除`） |

## 5. 非功能性需求与多状态边界

### 5.1 全局异常与多状态要求
每个数据驱动页面均须覆盖 5 种完整视觉状态：
1. **初始加载态（Loading）**：采用与最终卡片轮廓一致的骨架屏（Skeleton），禁止全屏阻塞白屏。
2. **数据正常态（Content）**：支持下拉刷新（Pull-to-Refresh），局部刷新保留原数据并显示顶部轻量进度提示。
3. **空状态（Empty）**：提供语义插画/线性图标 + 简短说明 + 主引导按钮（如无服务器时的「添加面板」、搜索无结果时的「清空筛选」）。
4. **网络/接口异常态（Error）**：区分「网络不可达/超时」「TLS 证书不受信任」「401 鉴权失效」「5xx 面板异常」，给出明确中文原因与「重试 / 检查连接」操作按钮。
5. **操作中防抖态（Submitting）**：写操作请求中禁用对应按钮并展示加载指示，结束后弹出语义 Toast（成功/失败）并立即刷新该项最新状态。

### 5.2 性能与安全基线
- **轮询资源控制**：概览页自动轮询仅在 App 处于前台且位于概览/监控下钻页时激活；切入后台或切换至其他 Tab 时自动暂停轮询，切回后立即恢复刷新。
- **日志内存保护**：容器/编排/任务日志单次渲染限定上限（默认拉取最新 200 行，可切换至 500/1000 行），避免长日志导致移动端内存暴涨卡顿。
- **凭据与隐私安全**：本地存储强制走平台安全区（iOS Keychain / Android Keystore）；日志上报与崩溃收集严禁包含 API-Key、密码、Cookie/Token。

## 6. 验收标准（Given-When-Then）

### AC-01：多实例启动路由与默认服务器切换
- **AC-01.1（首次无服务器启动）**
  - **Given** 用户首次打开 HWPanel，本地未保存任何 1Panel 服务器实例
  - **When** App 完成启动初始化
  - **Then** 进入「全部面板总览页」空状态，清晰展示引导说明与「添加服务器」主按钮。
- **AC-01.2（未设默认机启动）**
  - **Given** 本地已保存 2 台及以上服务器，且均未设为默认服务器
  - **When** 用户冷启动 App
  - **Then** 默认进入「全部面板总览页」，以卡片流展示全部服务器的在线状态、备注名、地址及 CPU/内存摘要。
- **AC-01.3（已设默认机启动与快速切换）**
  - **Given** 用户已将服务器 A 设为「默认服务器」
  - **When** 用户冷启动 App
  - **Then** 直接进入服务器 A 的「单机概览页（Tab 1）」，且底部展示 5 Tab 导航栏；
  - **When** 用户点击顶部服务器切换胶囊并选择服务器 B（或点击「查看全部面板」）
  - **Then** 1 秒内开始切换上下文并刷新为服务器 B 的概览数据（或返回全部面板总览页）。

### AC-02：登录鉴权与连接测试（API-Key / 用户名密码）
- **AC-02.1（API-Key 登录成功）**
  - **Given** 用户处于「添加服务器页」并选择「API-Key」模式，填入有效的 1Panel v2 地址与 API-Key
  - **When** 用户点击「测试连接」
  - **Then** 按钮进入加载态，测试通过后展示绿色成功横幅及识别到的 1Panel 版本号，点击「保存并连接」后凭据安全写入系统 Keychain/Keystore 并进入列表/概览。
- **AC-02.2（用户名密码登录与安全入口/验证码/MFA 边界）**
  - **Given** 用户选择「用户名密码」模式连接一台开启了安全入口或 MFA 的 1Panel v2 实例
  - **When** 用户填写账号密码并提交，面板返回需要图形验证码或 MFA 挑战
  - **Then** 客户端弹出对应的验证码输入框或 6 位 MFA 输入步骤，验证通过后成功保存连接；若安全入口错误或 IP 不在白名单，则展示明确的中文错误原因与排查提示。
- **AC-02.3（自签名证书保护）**
  - **Given** 目标面板使用自签名 HTTPS 证书，且「允许自签名证书」开关处于默认关闭状态
  - **When** 用户点击「测试连接」
  - **Then** 连接被拒绝并提示证书不受信任；当用户手动开启「允许自签名证书」开关（界面展示风险提示）后再次测试，可正常完成连接。

### AC-03：单机概览页与指标下钻
- **AC-03.1（核心指标展示与状态配色）**
  - **Given** 用户位于在线服务器的「概览页（Tab 1）」
  - **When** 监控接口返回最新资源数据
  - **Then** 页面以卡片式呈现 CPU（环图 + Load 1/5/15）、内存（环图 + Swap）、磁盘（环图 + I/O 速率）、网络（上下行速率 + 累计流量）及进程 Top5（支持按 CPU/内存切换排序）；资源使用率 `≥ 90%` 时环图/状态色自动切换为危险红。
- **AC-03.2（卡片下钻与监控历史降级）**
  - **Given** 用户位于概览页
  - **When** 用户点击 CPU、内存、磁盘、网络或进程 Top5 卡片
  - **Then** 进入对应下钻详情页展示细粒度数据（多核/多挂载点/多网卡/完整只读进程列表）与 `1h/6h/24h` 历史趋势图；若面板未开启监控历史，则趋势图区域展示中文引导空态而不影响实时数据展示；进程下钻页不提供结束进程（Kill）按钮。
- **AC-03.3（后台暂停轮询）**
  - **Given** 概览页按 5 秒间隔自动刷新监控数据
  - **When** 用户切换至「容器」Tab 或将 App 切入系统后台
  - **Then** 自动轮询立即暂停；切回概览页时立即触发一次刷新并恢复定时轮询。

### AC-04：容器与 Compose 编排管理
- **AC-04.1（容器列表、筛选与生命周期操作）**
  - **Given** 用户切换至底部 Tab 2「容器」并处于「容器」分段
  - **When** 用户输入关键词或点击「运行中 / 已停止」筛选胶囊
  - **Then** 列表即时过滤匹配容器；点击运行中容器的「停止」或「重启」并确认后，按钮显示加载防抖态，操作完成后弹出结果 Toast 并刷新容器状态；删除容器必须经过展示容器名与不可逆提示的强二次确认弹窗。
- **AC-04.2（容器详情与实时日志）**
  - **Given** 用户点击任一容器进入「容器详情页」并切换至「运行日志」
  - **When** 用户切换行数（100/500/1000）、输入关键词搜索或点击复制
  - **Then** 日志区域以等宽字体正确展示并高亮搜索词（可选行数 `100 / 200 / 500 / 1000`，默认 `200` 行），一键复制将当前可见日志写入系统剪贴板并给出成功反馈。
- **AC-04.3（Compose 编排操控与 YAML 编辑校验）**
  - **Given** 用户在 Tab 2 切换至「编排」分段并进入某编排详情的「YAML 配置」
  - **When** 用户编辑 YAML 引入非法缩进或语法错误并点击「保存」
  - **Then** 客户端拦截提交并在错误处提示语法问题；修正为合法 YAML 后可正常保存，且支持对该编排执行启动、停止、重启、查看日志，以及带强提示二次确认的「重建」与「删除」操作。

### AC-05：应用商店安装、升级与卸载
- **AC-05.1（浏览与参数化安装）**
  - **Given** 用户进入底部 Tab 3「应用」的「应用商店」分段，选择一款应用进入安装配置页

- **AC-05.2（升级与高危卸载确认）**
  - **Given** 用户在「已安装」列表中打开一个已安装应用详情页
  - **When** 用户点击「升级」并选择目标版本确认
  - **Then** 进入异步升级任务进度与日志页；
  - **When** 用户点击「卸载」
  - **Then** 弹出强提示二次确认弹窗，明确展示应用名称与两个**默认未勾选**的复选框（「同时删除数据与备份」「同时删除关联镜像」），用户确认后方可执行卸载。

### AC-06：计划任务管理
- **AC-06.1（查看、启停、手动执行与日志）**
  - **Given** 用户进入底部 Tab 4「任务」
  - **When** 页面加载完成

### AC-08：5 Tab 布局与一期范围守护
- **Given** 用户处于任意单机主页面
- **When** 检视底部导航栏及全部二级入口
- **Then** 底部导航严格呈现「概览 / 容器 / 应用 / 任务 / 更多」5 个 Tab，且全应用不包含终端、文件管理、AI 助手、网站配置编辑、新建计划任务、新建 Compose、生物识别锁等二期/范围外功能入口。
